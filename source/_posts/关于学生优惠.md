因为最近在申请 GitHub 学生包以及 JetBrains 的学生优惠方面踩了不少坑，所以写一篇博客记录一下申请流程以及常见踩坑内容。

## GitHub 学生包（GitHub Student Developer Pack）

GitHub 学生包包含了非常多的开发者工具和服务，包括 GitHub Copilot、各种云服务的 credits、域名、JetBrains 全家桶等等，非常值得申请。

### 申请条件

1. **年满 13 周岁**
2. **目前正在接受高等教育**（大专、本科、硕士、博士均可）
3. **拥有学校邮箱** 或 能提供有效的在读证明

### 申请流程

1. 打开 [GitHub Education](https://education.github.com/benefits) 页面，点击 "Get student benefits"
2. 使用你的 GitHub 账号登录
3. 选择学校（如果列表里没有，可以手动输入学校名）
4. **验证学生身份**（二选一）：
   - 使用学校 `.edu` 或 `.edu.cn` 邮箱直接验证
   - 上传在读证明/学生证照片进行人工审核
5. 提交申请，等待审核

### 常见踩坑与解决方案

#### 1. 没有 `.edu` 邮箱怎么办？

国内很多高校的邮箱后缀不是 `.edu` 而是 `.edu.cn`，GitHub 一般也能识别。如果你的学校邮箱后缀比较特殊（比如 `@mail.xxx.edu.cn`），可以尝试：
- 在 GitHub Settings → Emails 中添加你的学校邮箱并验证
- 申请时选择该邮箱作为验证方式

如果邮箱验证不通过，可以转为上传学信网的在读证明（推荐英文版）。

#### 2. 上传证件照片被拒

- **拍照清晰度要求高**：用手机拍照时确保光线充足、文字清晰可辨
- **需要包含有效日期**：证件上必须能看到入学日期和预期毕业日期
- **推荐使用学信网在线验证报告**：登录[学信网](https://www.chsi.com.cn/)，下载英文版在读证明 PDF，截图上传
- **不要 P 图或用扫描件**：GitHub 会检测图片是否被修改

#### 3. 定位问题

GitHub 在验证时会检查你的地理位置（通过 IP 和浏览器定位），确保：
- **关闭 VPN/代理**：使用国内网络直连申请
- **允许浏览器定位**：申请页面会请求定位权限，一定要允许
- **定位在学校附近**：如果可能的话，在学校网络环境下申请

#### 4. 审核时间

- 邮箱验证：通常几分钟到几小时
- 人工审核（上传证件）：通常 3-15 个工作日
- 如果超过两周没有回复，可以尝试重新提交或发邮件联系 `education@github.com`

## JetBrains 学生优惠

JetBrains 提供全家桶（IntelliJ IDEA Ultimate、PyCharm Professional、WebStorm、CLion 等）的免费教育许可证。

### 申请条件

1. 在校学生（本科/硕士/博士）
2. 拥有学校邮箱（`.edu` 或 `.edu.cn`）
3. 或能提供其他学生身份证明

### 申请流程

1. 打开 [JetBrains 免费教育许可证](https://www.jetbrains.com/shop/eform/students) 申请页面
2. 选择验证方式：
   - **官方学校邮箱**（最快，推荐）
   - **ISIC/ITIC 卡**
   - **官方文件**（学生证、在读证明等）
3. 填写个人信息和学校信息
4. 提交后到邮箱中确认验证邮件
5. 创建/登录 JetBrains Account，即可获得许可证

### 常见踩坑与解决方案

#### 1. 学校邮箱收不到验证邮件

- 检查垃圾邮件文件夹
- 部分学校邮箱可能屏蔽了 JetBrains 的邮件，可以尝试设置白名单
- 如果实在收不到，可以用「官方文件」方式申请，上传学生证照片

#### 2. 邮箱后缀不被认可

有些学校的邮箱后缀比较特殊，JetBrains 可能不在其数据库中。解决方法：
- 选择「官方文件」验证方式，上传学信网在读证明
- 联系 JetBrains 教育支持团队：`education@jetbrains.com`

#### 3. 许可证续期

- JetBrains 教育许可证有效期为 **一年**，到期前会收到续期邮件
- 续期时需要**重新验证学生身份**（确保还在读）
- 建议设个日历提醒，过期后需要重新走一遍申请流程

#### 4. 在 IDE 中激活

获得许可证后：
1. 打开任意 JetBrains IDE
2. 菜单：Help → Register
3. 选择 "JetBrains Account" 登录方式
4. 用申请时的账号登录即可激活

### 注意事项

- 教育许可证**仅限个人学习使用**，不可用于商业项目
- 毕业后许可证不再续期，需购买个人/商业许可
- 如果你已经通过 GitHub Student Pack 获得了 JetBrains 许可证，两者是等价的，不需要重复申请

## 总结

- 优先办理 **GitHub 学生包**，因为它包含了很多其他服务的入口（包括 JetBrains）
- 所有申请的核心就是**证明你是在校学生**，提前准备好学校邮箱和学信网在读证明
- 定位和网络环境很关键，尤其是 GitHub 学生包申请时
- 申请被拒不要慌，按照要求重新提交即可，多试几次一般都能过
